## Context

ADR-017 让渲染直接读取 archive/feed index，带来两个问题：

- AI 判定为 `skip` 的文章仍然出现在每日页和 JSON Feed；
- JSON Feed 的 `home_page_url` 被部署 base URL 覆盖，导致所有 feed 都指向聚合站首页；无 GUID 记录的锚点也与 JSON item id 不一致。

归档必须保留，但“站点是否展示”和“对外 URL 契约”需要独立决定。

## Decision

- 分类为 `skip` 时追加 `category=skip` 的 annotation；渲染时以最新 annotation 为准隐藏该 GUID。
- 隐藏范围：
  - 每日 HTML；
  - per-feed JSON Feed；
  - `_site/archive/YYYY/MM/DD.md` 中供 Range 读取的正文。
- 隐藏只影响 `_site`，不删除 `data` 分支 archive；之后出现更新的非 skip annotation 会恢复显示。
- 从过滤后的 Markdown 中删除记录时，按原记录字节切片复制，并重映射 JSON 里的 `offset` / `length` / `body_offset` / `body_len`，保证 Range 仍然命中正确正文。
- JSON Feed：
  - `home_page_url` 指向源站 `site_url`；
  - `feed_url` 指向聚合站上的 `<base>/feeds/<id>.json`；
  - 无 base URL 时使用相对路径。
- 锚点规则统一为：有 GUID 用 GUID，否则 `article-<archive offset>`；JSON item id 与每日页锚点一致。

## Consequences

优点：

- `skip` 从“只影响 output”变成真正的站点过滤器。
- JSON Feed 消费方可以正确回到源站。
- Range 偏移在过滤后仍然可靠。

缺点：

- 渲染需要多一次全量 index 扫描并重建被过滤的 Markdown 副本。
- skip 不是删除；archive 仍保留被隐藏内容。
